# NasFinder.com

NasFinder.com은 armsone이 만드는 앱의 기능, 화면, 진행 상황, 사용법과 배포 정보를 소개하는 웹사이트입니다.

이 저장소는 홈페이지 소스를 투명하게 공개하고 독립적으로 보존하기 위한 공개 미러입니다. 운영 비밀번호, API 키, 인증 토큰과 방문자 개인정보는 저장소에 포함하지 않습니다.

## 앱

- 나스파인더 (NasFinder)
- 한클립 (HanClip)
- 에스텐드 (S.tand)
- CCMB
- TrackpadGuard

## 로컬 실행

```sh
npm ci
npm run dev
```

## 검증

```sh
npm run build
```

## TestFlight 상태 갱신

TestFlight 빌드가 업로드되면 `app/testflight.ts`에서 해당 앱의 빌드 번호, ISO 8601 업로드 시각과 공개 참여 링크를 갱신합니다. 홈페이지는 업로드 시각부터 90일 만료일까지 남은 기간을 자동으로 계산합니다. 확인되지 않은 날짜는 입력하지 않습니다.

## 공개 전 확인

- App Store·TestFlight·Google Play·GitHub Release 링크와 현재 버전
- 개인정보처리방침 시행일과 법적 운영자 정보

- 실제 앱 화면의 개인정보 제거

## 보안

비밀번호, API 키, 인증 토큰과 실제 운영 환경값은 커밋하지 않습니다. 보안 문제를 발견했다면 공개 이슈에 민감한 내용을 적지 말고 GitHub의 비공개 보안 신고 기능을 이용해 주세요.

## 저작권

별도의 라이선스를 부여하지 않은 소스 코드, 문구와 이미지의 권리는 저작권자에게 있습니다. 저장소 공개는 별도의 복제·배포·변형 허가를 뜻하지 않습니다.
