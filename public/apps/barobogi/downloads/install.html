바로보기 웹 번역 — 도움말

버전 0.3.0 · Windows Chrome / Naver Whale · 설치 및 첫 사용 안내

  1. 처음 사용(3단계)
  2. 압축 풀어 설치하기
  3. 새 버전으로 업데이트
  4. 문제 해결

1. 처음 사용(3단계)

  1. 이미지가 있는 웹페이지에서 툴바의 바로보기 아이콘을 누릅니다.
  2. 처음 한 번 번역 준비하기를 누르고, 브라우저가 물으면 허용을 누릅니다. 번역에 필요한 파일(약 640MB)을 이 PC에 받아 보관합니다. 팝업에 번역 준비 중 35%처럼 진행이 보이며, 팝업을 닫아도 계속 받습니다.
  3. 준비됨이 되면 지금 페이지를 바로 번역합니다. 다음부터는 아이콘만 누르면 번역 보기로 바뀝니다.
  • 번역: 모든 웹사이트에서 자동 번역을 켭니다(처음 한 번 접근 허용을 묻습니다. 허용하지 않으면 지금 페이지만 번역).
  • 원문: 자동 번역을 끄고 원래 화면으로 되돌립니다.
  • 그림 속 글자는 언어를 고르지 않아도 영어·한국어·일본어(세로쓰기 포함)·중국어(간체)를 자동으로 읽습니다. 결과가 이상한 그림에만 팝업의 추가 설정에서 읽기 방식을 바꿔 보세요.
  • 페이지의 일반 글자는 브라우저 번역(Chrome: 마우스 오른쪽 → 번역, Whale: 주소창 번역 버튼)을 권장합니다.
  • 번역은 모두 이 PC 안에서 합니다. 번역할 글자나 그림을 서버로 보내지 않습니다. 인터넷은 처음 파일을 받을 때만 씁니다.

2. 압축 풀어 설치하기

Chrome에는 Barobogi-Windows-Chrome-0.3.0.zip, Whale에는 Barobogi-Windows-Whale-0.3.0.zip을 씁니다. Chrome은 116 이상이 필요합니다.

  1. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 압축 풀기(모두 압축 풀기…)를 고릅니다. 앞으로 지우지 않을 곳(예: 문서\Barobogi\Chrome)에 풉니다. Chrome용과 Whale용은 서로 다른 폴더에 푸세요.
  2. 주소창에 chrome://extensions(Whale은 whale://extensions)를 입력하고 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다(Whale: 압축 해제된 확장앱 로드)를 누르고, manifest.json이 바로 보이는 폴더를 고릅니다. 안쪽에 폴더가 하나 더 있으면 그 안쪽 폴더입니다.
  4. 버전이 0.3.0인지 확인하고, 퍼즐 모양(확장 프로그램) 메뉴에서 바로보기 웹 번역을 툴바에 고정합니다.

설치해도 새 창이나 탭이 열리지 않습니다. 툴바 아이콘을 누르면 시작합니다. Chrome과 Whale은 저장소를 공유하지 않아 브라우저마다 파일을 한 번씩 받습니다.

3. 새 버전으로 업데이트(받은 파일 유지)

  1. 새 ZIP을 풀어, 처음 설치할 때 고른 폴더의 내용을 새 파일로 바꿉니다. 폴더 위치·이름은 그대로 둡니다.
  2. 확장 관리 페이지에서 바로보기 웹 번역의 새로고침(↻)을 누르고, 버전이 바뀌었는지 확인합니다.

확장을 "삭제"하지 마세요. 삭제하면 받은 파일(약 640MB)과 설정도 지워져 다시 받아야 합니다. 다른 폴더를 새로 로드해도 별개의 확장으로 취급되어 다시 받아야 합니다. 같은 폴더에서 업데이트하면 이전 버전에서 받은 파일을 그대로 씁니다.

4. 문제 해결

"허용하지 않아 파일을 받지 않았어요"
번역 준비하기를 다시 누르고 브라우저가 묻는 창에서 허용을 고르세요. 이 허용은 번역 파일 주소에서 받을 때만 씁니다.
"인터넷 응답이 없어 멈췄어요" / "파일을 받지 못했어요"
인터넷 연결(회사 방화벽·프록시 포함)을 확인하고 다시 시도를 누르세요. 다 받은 파일은 그대로 두고 나머지만 받습니다.
"저장 공간이 부족해요"
브라우저가 설치된 드라이브(보통 C:)에 1GB 이상 비운 뒤 다시 시도하세요.
"준비가 중간에 멈췄어요"
브라우저를 닫는 등으로 받기가 멈춘 경우입니다. 이어서 준비하기를 누르세요.
"이 브라우저 버전에서는 바로보기를 쓸 수 없어요" / 팝업에 "업데이트 필요"
브라우저가 오래되어 필요한 기능이 없습니다. 브라우저를 최신 버전으로 업데이트하세요.
"원문 언어를 판별하지 못한 문장은 번역하지 않았습니다"
한자만 있는 짧은 문구처럼 근거가 부족한 경우입니다. 추가 설정의 원문 언어를 직접 고르면 번역됩니다.
"일부 그림의 글자를 읽지 못했거나 2분을 넘겨 멈췄어요"
다시 번역을 누르세요. 계속되면 추가 설정에서 그림 글자 읽기 방식을 바꿔 보세요.
"이 페이지는 번역할 수 없어요"
브라우저 내부 페이지·확장 스토어·새 탭·로컬 파일은 브라우저가 확장 접근을 막습니다. 일반 웹사이트에서 사용하세요.

한계: 번역 품질은 최신 클라우드 번역기보다 낮을 수 있고, 느린 PC에서는 그림마다 시간이 걸립니다. 중국어(번체) 출력, 중국어 세로쓰기 인식은 보장하지 않습니다. 실제 Windows PC에서의 속도·정확도는 아직 확인하지 않았습니다.

저장하는 것: 설정값, 번역 파일(브라우저 저장소), 받는 중 진행 표시(받은 양). 페이지 글자·그림·번역 결과·방문 기록은 저장하지 않습니다. 제3자 라이선스: 확장 폴더의 vendor/licenses, ocr, fonts 안 라이선스 파일.
