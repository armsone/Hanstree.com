바로보기 웹 번역 — 설치·사용 도움말

버전 0.2.0(테스트용) · Windows Chrome / Naver Whale · Chrome·Whale 설치와 사용을 위한 웹 안내입니다. ZIP 안의 도움말은 help.html이며, 설치 후 팝업에서도 열 수 있습니다.

  1. Chrome에 설치
  2. Whale에 설치
  3. 처음 한 번: 번역 모델 내려받기(약 640MB)
  4. 첫 이미지 번역
  5. 이미지 글자 자동 인식(여러 언어·가로/세로)
  6. 새 버전으로 업데이트(모델 다시 받지 않기)
  7. 문제 해결(화면에 보이는 상태별)

1. Chrome에 설치

Chrome에는 Barobogi-Windows-Chrome-0.2.0.zip을 씁니다(Whale용 ZIP과 다릅니다). Chrome 116 이상이 필요합니다.

  1. 파일 탐색기에서 다운로드 폴더를 열고 Barobogi-Windows-Chrome-0.2.0.zip을 찾습니다.
  2. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 압축 풀기(모두 압축 풀기…)를 고릅니다. 압축을 풀 위치를 정하고 압축 풀기를 누릅니다. 앞으로 지우지 않을 곳(예: 문서\Barobogi\Chrome)을 권장합니다. 브라우저가 이 폴더에서 확장을 실행하므로 폴더를 지우거나 옮기면 확장이 멈춥니다.
  3. 압축을 푼 폴더를 열어 manifest.json 파일이 바로 보이는 폴더인지 확인합니다. 그 안에 폴더가 하나 더 있고 그 안에 manifest.json이 있다면, 그 안쪽 폴더가 고를 폴더입니다. ZIP 파일 자체나 그 위 폴더를 고르면 설치되지 않습니다.
  4. Chrome 주소창에 chrome://extensions를 입력하고 Enter를 누릅니다.
  5. 오른쪽 위의 개발자 모드 스위치를 켭니다.
  6. 왼쪽 위에 나타난 압축해제된 확장 프로그램을 로드합니다 버튼을 누르고, 3단계에서 확인한 폴더(manifest.json이 들어 있는 폴더)를 고릅니다.
  7. 목록에 바로보기 웹 번역 카드가 생기고 버전이 0.2.0인지 확인합니다. 오류가 보이면 폴더를 잘못 고른 경우가 대부분입니다(3단계 확인).
  8. 툴바에 고정: 주소창 오른쪽 퍼즐 모양(확장 프로그램) 아이콘을 누르고, 바로보기 웹 번역 옆의 압정(고정) 아이콘을 누릅니다.
  9. 툴바의 바로보기 아이콘을 누르면 팝업이 열립니다. 설치 직후에는 번역 엔진 창이 한 번 자동으로 열립니다(안 열리면 팝업의 번역 엔진 창 열기). 이어서 3. 모델 내려받기로 갑니다.

2. Naver Whale에 설치

Whale에는 Barobogi-Windows-Whale-0.2.0.zip을 씁니다(Chrome용 ZIP과 다릅니다. Whale 패키지에는 Chrome 사이드패널 설정이 없습니다).

  1. 파일 탐색기에서 다운로드 폴더를 열고 Barobogi-Windows-Whale-0.2.0.zip을 찾습니다.
  2. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 압축 풀기(모두 압축 풀기…)를 고릅니다. 지우지 않을 위치(예: 문서\Barobogi\Whale)에 풉니다. Chrome용과 다른 폴더에 푸세요.
  3. 압축을 푼 폴더를 열어 manifest.json 파일이 바로 보이는 폴더인지 확인합니다(안쪽에 폴더가 하나 더 있으면 그 안쪽 폴더).
  4. Whale 주소창에 whale://extensions를 입력하고 Enter를 누릅니다.
  5. 개발자 모드 스위치를 켭니다.
  6. 압축 해제된 확장앱 로드 버튼(Whale 버전에 따라 이름이 조금 다를 수 있음)을 누르고, 3단계의 폴더를 고릅니다.
  7. 목록에 바로보기 웹 번역이 생기고 버전이 0.2.0인지 확인합니다.
  8. 툴바에 아이콘이 보이지 않으면 Whale의 확장앱 버튼(또는 확장앱 관리 메뉴)에서 바로보기 웹 번역을 툴바에 표시하도록 설정합니다(메뉴 위치는 Whale 버전에 따라 다를 수 있습니다).
  9. 툴바의 바로보기 아이콘을 누르면 팝업이 열립니다. Whale에서는 사이드바 대신 번역 엔진 창(작은 별도 창)을 씁니다. 이어서 3. 모델 내려받기로 갑니다.

Chrome과 Whale은 저장소를 공유하지 않습니다. 두 브라우저에 모두 설치하면 모델(약 640MB)을 브라우저마다 한 번씩 받고, 디스크도 각각 씁니다.

3. 처음 한 번: 번역 모델 내려받기(약 640MB)

이미지 글자 인식(OCR) 데이터는 확장 안에 들어 있어 따로 받지 않습니다. 번역 모델(M2M100 418M, 639,977,588바이트 ≈ 640.0MB)만 처음 한 번 받습니다. 버튼을 누르기 전에는 아무것도 내려받지 않습니다.

  1. 번역 엔진 창에서 모델 내려받기 (약 640MB)를 누릅니다. 누르는 즉시 상태가 브라우저 권한 요청 중으로 바뀝니다.
  2. 브라우저가 huggingface.co(와 그 다운로드 서버 *.hf.co) 접근 허용을 물으면 허용을 누릅니다. 이 확장이 받는 것은 고정된 모델 파일 7개뿐이며, 번역할 글자·이미지·쿠키는 보내지 않습니다. 거절해도 공개 주소로 받기를 시도합니다. 확인 창이 안 보이면 엔진 창을 한 번 클릭해 앞으로 가져오세요.
  3. 상태가 서버 연결 중 → 내려받는 중 NN%로 바뀝니다. 큰 글씨의 퍼센트와 진행 막대, 받은 양: 123.4MB / 640.0MB, 파일 6/7: encoder_model_quantized.onnx — …MB / 287.9MB처럼 실제로 받은 바이트가 표시됩니다(1MB = 1,000,000바이트).
  4. 파일 하나를 다 받으면 검증·저장 중(크기와 SHA-256/SHA-1 해시 확인)이 잠깐 보입니다. 퍼센트는 모든 파일 검증과 완료 표시 저장이 끝나기 전에는 99%를 넘지 않습니다.
  5. 위쪽 단계 표시가 1. 내려받기 → 2. 검증·저장 → 3. 메모리에 불러오기 → 4. 준비됨 순서로 바뀝니다. 메모리에 불러오는 중은 다운로드가 끝난 뒤 저장된 모델을 메모리에 올리는 단계로, 네트워크를 쓰지 않으며 PC에 따라 시간이 걸립니다.
  6. 준비됨이 보이면 끝입니다. 다음부터는 엔진 창을 열 때 저장된 모델을 불러오기만 합니다.

내려받는 동안 번역 엔진 창을 닫지 마세요. 내려받기는 그 창 안에서 진행되므로 창을 닫으면 멈춥니다(닫으려 하면 브라우저가 확인을 묻습니다). 다른 탭을 쓰는 것은 괜찮고, 창을 최소화해도 됩니다.

중간에 멈췄을 때(이어받기의 실제 동작): 크기·해시 검증을 마친 파일은 저장되어 다시 받지 않습니다. 받던 도중 끊긴 파일은 처음부터 다시 받습니다(파일 중간부터 이어받지는 않음). 가장 큰 파일은 약 288MB·344MB이므로, 그 파일 도중에 끊기면 그만큼 다시 받습니다.

4. 첫 이미지 번역

  1. 번역 엔진 창을 열어 둡니다(상태 준비됨). 엔진 창을 닫으면 번역이 멈춥니다.
  2. 이미지가 있는 일반 웹사이트(주소가 http:// 또는 https://로 시작)로 갑니다.
  3. 툴바의 바로보기 아이콘을 눌러 팝업을 엽니다.
  4. 번역 언어(예: 한국어)를 고릅니다. 원문 언어는 자동 감지, 이미지 글자는 자동(여러 언어·가로/세로)을 그대로 둡니다.
  5. 번역 시작을 누릅니다. 지금 화면에 보이는 부분을 캡처해 이미지 속 글자를 인식하고, 번역을 이미지 위 같은 자리에 겹쳐 그립니다. 진행 상황은 엔진 창의 처리 현황에 이미지 1/3 · 가로 인식(일본어·한국어·중국어 간체·영어) 40%처럼 보입니다.
  6. 원문 보기를 누르면 원래 화면으로 돌아갑니다. 다시 번역 시작을 누르면 번역 보기로 바뀝니다.

브라우저 내부 페이지(chrome://…, whale://…), 확장 스토어, 새 탭·빈 페이지, 로컬 파일(file://) 등은 브라우저가 확장 접근을 막아 번역할 수 없습니다. 팝업에 "이 페이지는 번역할 수 없습니다"가 보이면 일반 웹사이트에서 시도하세요. 수동 번역은 누른 시점에 보이는 부분만 번역합니다(스크롤을 따라가려면 "모든 사이트에서 자동 번역").

5. 이미지 글자 자동 인식(여러 언어·가로/세로)

  • 기본값 자동은 언어를 고르지 않아도 한 이미지 안에 섞인 영어·한국어·일본어·중국어(간체)를 한 번에 읽습니다(Tesseract 다국어 가로 인식). 일본어 데이터의 세로 하위 언어(jpn_vert)도 함께 실어, Tesseract가 세로 블록으로 본 곳은 같은 인식 안에서 세로 모델로 읽습니다.
  • 가로 결과와 관계없이 일본어 세로 모델로 이미지 전체를 자동 배치(PSM 3)로 한 번 더 스캔합니다. 가로 인식이 놓친 세로 열도 여기서 찾습니다. 그다음 세로 근거(세로 블록, 위→아래 글자 흐름, 세로 열을 가로로 읽은 격자 모양)가 강한 곳만 최대 6곳 잘라 세로 한 덩어리(PSM 5)로 정밀하게 다시 읽습니다. 이미지 전체를 세로로 단정하지 않고, 믿을 만한 가로 글이 있는 곳은 잘라 읽지 않습니다.
  • 겹치는 가로·세로 결과는 쌍마다 신뢰도·글자 방향·문자 종류로 비교해 하나만 남깁니다. 신뢰도 높은 영어·한국어 가로 글은 세로 결과가 지우지 못하고, 큰 세로 문단이 옆 가로 글까지 지우지 않게 겹친 낱말만 뺍니다. 가로 인식이 글자를 보지 못한 곳의 세로 결과는 근거가 강할 때만 남깁니다(없는 글자를 만들지 않음).
  • 언어가 섞인 문단은 문자 종류(한글 / 한자·가나 / 라틴)가 같은 줄끼리 나눠, 조각마다 원문 언어와 가로/세로를 따로 정해 번역합니다. 가나 없이 한자만 있는 짧은 문구는 일본어인지 중국어인지 근거(같은 이미지의 가나, 페이지 언어 표시)가 없으면 번역하지 않고 남깁니다 — 그럴 땐 팝업의 원문 언어를 직접 고르세요.
  • 인식 결과가 나쁜 이미지에만 이미지 글자에서 수동 항목(예: 일본어 세로쓰기만)을 고르세요. 수동 항목은 그 언어 하나로만 읽습니다.
  • 한계: 세로 인식 데이터는 일본어용뿐이라 중국어 세로쓰기는 잘 읽지 못할 수 있습니다. 중국어는 간체 데이터만 있어 번체 글자 인식은 보장하지 않습니다. 손글씨·장식 글꼴·작은 글자·복잡한 배경에서는 결과가 나쁠 수 있고, 배치 분석이 글자로 보지 못한 세로 열은 전체 스캔으로도 놓칠 수 있습니다. 세로 단계까지 하므로 이미지마다 시간이 더 걸립니다. 실제 Windows 브라우저·실제 이미지로 정확도를 검증하지 않았습니다.
  • 세로 단계가 실패하거나 멈추면 가로 결과는 그대로 보이고, 페이지 상태에 "세로쓰기 인식 단계가 실패…" 경고가 보입니다(조용히 빠뜨리지 않음).

6. 새 버전으로 업데이트(모델 다시 받지 않기)

  1. 새 버전 ZIP을 받아 압축을 풉니다.
  2. 기존 확장 폴더(처음 설치할 때 고른 폴더)의 내용을 새로 푼 파일로 바꿉니다(기존 폴더 안 파일을 지우고 새 파일을 복사). 폴더 위치·이름은 그대로 둡니다.
  3. chrome://extensions(Whale은 whale://extensions)에서 바로보기 웹 번역 카드의 새로고침(↻) 버튼을 누릅니다.
  4. 카드의 버전이 새 버전으로 바뀌었는지 확인합니다. 열려 있던 번역 엔진 창은 닫고 다시 여세요.

확장을 "삭제"하지 마세요. 삭제하면 이 확장의 저장소(내려받은 모델 약 640MB와 설정)도 함께 지워져 다시 받아야 합니다. 또 다른 폴더를 새로 "압축해제된 확장 프로그램"으로 로드하면 브라우저가 별개의 확장으로 취급해(폴더마다 확장 ID가 다름) 모델을 다시 받아야 합니다.

0.1.x에서 올리면: 설정과 모델은 그대로 유지됩니다. 단, 예전 기본값이던 이미지 글자 "일본어(가로쓰기)"는 한 번만 자동으로 바뀝니다 (자동이 일본어 가로를 포함하기 때문). 일본어 세로쓰기·영어·중국어·한국어를 골라 두었다면 그대로 남습니다.

7. 문제 해결(화면에 보이는 상태별)

팝업: 엔진 꺼짐 / "'번역 엔진 창 열기'로 엔진을 먼저 켜 주세요"
번역 엔진 창이 닫혀 있습니다. 팝업의 번역 엔진 창 열기를 누르고 창을 열어 두세요.
팝업: "모델을 내려받던 번역 엔진 창이 닫혀 내려받기가 멈췄습니다" / 엔진 창: 중단됨(엔진 창이 닫힘)
엔진 창을 다시 열면 저장된 파일을 확인한 뒤 이어서 내려받기 버튼이 보입니다. 검증된 파일은 건너뛰고, 끊긴 파일은 처음부터 받습니다.
브라우저 권한 요청 중(오래 그대로)
브라우저의 권한 확인 창이 다른 창 뒤에 숨어 있을 수 있습니다. 엔진 창을 클릭해 앞으로 가져오세요. 그래도 없으면 권한 요청 취소 후 다시 누르세요.
서버 연결 중이 오래 감 / "네트워크에서 N초째 데이터가 오지 않습니다"
실제로 바이트가 들어오지 않는 상태입니다(퍼센트를 꾸며 올리지 않습니다). 인터넷 연결·회사 방화벽·프록시를 확인하세요. 60초 동안 아무것도 오지 않으면 자동으로 멈추고 네트워크 응답 없음으로 중단됨이 됩니다. 다시 시도를 누르세요.
내려받기 실패: HTTP 403/404/5xx
모델 서버가 요청을 거절했거나 일시적으로 응답하지 않았습니다. 잠시 뒤 다시 시도하세요. 고정된 주소만 쓰므로 다른 서버로 바꾸지 않습니다.
"SHA-256이 다릅니다" / "해시가 다릅니다" / "크기가 다릅니다"
받은 파일이 고정 메타데이터와 다릅니다(전송 중 손상, 중간 프록시 등). 그 파일은 저장하지 않고 지웠습니다. 다시 시도하면 그 파일을 처음부터 다시 받습니다.
"저장 공간이 부족해 모델을 저장하지 못했습니다"
브라우저 프로필이 있는 드라이브(보통 C:)에 여유 공간을 1GB 이상 확보한 뒤 다시 시도하세요.
다른 엔진 창에서 내려받는 중 NN%
엔진 창(또는 Chrome 사이드패널)이 둘 이상 열려 있고 다른 쪽이 받는 중입니다(브라우저 잠금으로 한 곳에서만 받습니다). 그 창을 열어 두고 기다리세요. 끝나면 이 창도 저장된 모델을 다시 확인해 자동으로 불러옵니다.
"Web Locks API를 지원하지 않아… 내려받기를 시작하지 않았습니다"
여러 엔진 창의 동시 내려받기를 막을 수 없는 오래된 브라우저입니다. 브라우저를 최신 버전으로 업데이트하세요.
메모리에 불러오는 중(오래 걸림) / 불러오기 실패
다운로드는 이미 끝난 상태입니다. 느린 PC에서는 몇 분 걸릴 수 있습니다. 실패하면 다른 프로그램을 닫아 메모리를 확보하고 모델 불러오기 또는 번역 Worker 다시 시작을 누르세요.
"원문 언어를 판별하지 못한 문장은 번역하지 않았습니다"
한자만 있는 짧은 문구 등 근거가 부족한 경우입니다. 팝업의 원문 언어를 직접 고르면 번역됩니다.
"일부 이미지의 글자 인식이 실패하거나 2분을 넘겨 중단되었습니다"
OCR 엔진을 끝내고 다음 요청 때 새로 준비합니다. 다시 번역 시작을 누르세요. 계속되면 큰 이미지를 화면에 덜 보이게 하거나 수동 항목을 고르세요.
"일부 이미지에서 세로쓰기 인식 단계가 실패하거나 멈춰…"
가로 결과는 정상으로 표시했고 세로 글만 빠졌을 수 있습니다. 다시 번역 시작을 누르면 세로 인식기를 새로 준비합니다.
"이 페이지는 번역할 수 없습니다"
브라우저 내부 페이지·스토어·새 탭 등입니다. 일반 웹사이트에서 사용하세요.

번역·이미지 인식은 이 PC 안에서만 처리하며, 페이지 글자·이미지·번역 결과를 저장하거나 서버로 보내지 않습니다. 네트워크는 처음 모델 내려받기에만 씁니다. 저장하는 것: 설정값, 모델 파일(브라우저 Cache API), 내려받기 진행 중 표시(파일 이름·받은 바이트 수).
