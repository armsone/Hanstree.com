바로보기(Barobogi) 웹 번역 — Windows 테스트용 0.1.0
Chrome · 네이버 웨일(Whale) 확장(Manifest V3)

※ 이 안내는 배포 전 테스트 후보용입니다. Windows 실제 설치·실행·번역 속도·품질은
  아직 확인되지 않았습니다(Mac에서 소스·manifest·자원 수준으로만 점검했습니다).
  Chrome 웹 스토어/Whale 스토어에는 올라가 있지 않습니다.

핵심 기능
- 웹페이지 이미지 속 글자(특히 일본어 세로쓰기 jpn_vert)를 PC 안에서 인식(OCR)·번역해
  원본 이미지 위 같은 자리에 겹쳐 그립니다.
- 페이지의 일반 글자는 브라우저 기본 번역(Chrome: 마우스 오른쪽 → "한국어로 번역",
  Whale: 주소창의 번역 버튼) 사용을 권장합니다. 이 확장은 기본값이 "이미지 전용"이라
  브라우저가 번역한 페이지 글자를 덮어쓰지 않습니다.
- 번역 엔진(기본, 두 브라우저 공통): M2M100 418M(Meta, MIT 라이선스) ONNX 양자화본,
  Transformers.js로 로컬 실행. Chrome에서는 선택적으로 내장 Translator API도 쓸 수
  있습니다(필수 아님).

Chrome 요구 사항
- Chrome 116 이상 (출처: 앱 저장소 README)

설치(두 브라우저 모두 "압축해제된 확장 프로그램" 개발자 모드 방식)

[Chrome]
1. Barobogi-Windows-Chrome-0.1.0.zip을 원하는 폴더에 압축 해제(manifest.json이
   들어 있는 폴더).
2. 주소창에 chrome://extensions 입력 → 오른쪽 위 "개발자 모드" 켜기.
3. "압축해제된 확장 프로그램을 로드합니다" → 압축 푼 폴더 선택.

[Naver Whale]
1. Barobogi-Windows-Whale-0.1.0.zip을 원하는 폴더에 압축 해제.
2. 주소창에 whale://extensions 입력 → "개발자 모드" 켜기.
3. "압축해제된 확장앱을 로드"(이름이 조금 다를 수 있음) → 압축 푼 폴더 선택.

압축 푼 폴더는 지우지 마세요(브라우저가 그 폴더에서 확장을 실행합니다).

처음 실행: 모델 내려받기(설치 후 한 번)
1. 설치 후 번역 엔진 창이 자동으로 열립니다(안 열리면 툴바 아이콘 → "번역 엔진 창 열기").
2. "모델 내려받기(약 640MB)"를 누릅니다. huggingface.co 접근 허용을 물으면 허용하세요.
3. 크기·해시 검증을 마치면 "저장됨" → "준비됨"으로 바뀝니다.
4. 다음부터는 다시 받지 않습니다.
※ Chrome과 Whale은 저장소를 공유하지 않습니다. 두 브라우저 모두 설치하면 각각
  한 번씩 받습니다(총 약 1.28GB).

사용법
1. 번역 엔진 창을 열어 둡니다(엔진 창을 닫으면 번역이 멈춥니다).
2. 번역할 탭에서 툴바 아이콘 → 이미지 글자 언어 선택(예: 세로쓰기 만화는
   "일본어(세로쓰기)").
3. "번역 시작"으로 지금 보이는 이미지를 인식·번역해 같은 자리에 겹쳐 그립니다.
4. "원문 보기"로 언제든 되돌립니다.

개인정보
- 번역·OCR은 모두 이 PC 안에서 처리하며 외부 번역 서버로 보내지 않습니다.
- 네트워크 사용은 "처음 모델 내려받기"뿐이며, Hugging Face의 고정된 모델 파일 목록만
  받습니다. 번역할 글자·이미지·방문 기록은 저장하지 않습니다.
- Chrome·Whale 브라우저 자체 기본 번역 기능은 이 확장과 별개로 각 브라우저사의
  서비스·정책을 따릅니다.

실제 한계
- Windows 실기기 동작 미확인(설치·모델 다운로드·번역 속도·메모리 사용 등).
- 번역 품질은 M2M100 418M(비교적 작은 모델) 기준이며 상용 클라우드 번역기 수준을
  보장하지 않습니다.
- OCR 품질은 Mac 버전(Apple Vision)과 다릅니다.
- 이 확장은 브라우저 안에서만 동작하며, Mac 앱의 화면 전체·Mail 번역 기능은
  Windows 버전에 포함되지 않습니다.

자세한 내용은 앱 저장소의 README.md를 참고하세요.
